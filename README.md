# BlogSphere — Blog & Content Management System

BlogSphere is a modern and responsive Blog & Content Management System designed to simplify content creation, publishing, and editorial management.

## Features

- Professional admin dashboard
- Content analytics and statistics
- Create, edit and delete blog posts
- Rich-text content editor
- Draft and published post management
- Categories and tags management
- Search and filtering
- Comments management and moderation
- Blog authentication interface
- Public-facing blog interface
- Dark and light mode
- Responsive design
- LocalStorage data persistence

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Node.js / Express (backend sample)

## Run Locally

1. Clone or download this repository.
2. Extract the project folder.
3. Open the folder in VS Code.
4. Open index.html using Live Server.
5. Explore the BlogSphere application.

No database or backend server is required.

## Backend

Reference backend source code is included in the backend-sample/ directory.

The backend is provided for development and learning purposes and is not connected to the frontend.

## Deployment

This project supports GitHub Pages deployment.

An automated GitHub Actions workflow is included in .github/workflows/.
